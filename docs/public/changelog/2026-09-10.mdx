---
title: "SearXNG web search backend"
date: "2026-09-10"
---

The built-in `web_search` tool now supports a self-hosted [SearXNG](/integrations/searxng) instance as its preferred backend. Store the instance URL with `fabro secret set SEARXNG_URL http://searxng:8080` and agents search the web with no API key and no per-query cost.

Fabro selects the backend in order: SearXNG when `SEARXNG_URL` is present, then direct Brave Search (`BRAVE_SEARCH_API_KEY`), then Venice Search (`VENICE_API_KEY`). Users who never set the URL see no change. The instance must whitelist the `json` output format in its `settings.yml`; `fabro doctor` probes it and reports `searxng: configured and reachable` when the setup is correct.

Failed calls still do not fall back between providers, matching the existing behavior for Brave and Venice.
